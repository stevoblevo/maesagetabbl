# Changelog

Every version of the page, newest first. Each is a tag on `main`; `git checkout v6` shows you the page as it was. The lobby shows the version you are looking at.

## v8 · 2026-11-25
Tucked in: no body is drawn. A hood above a patchwork quilt, and the quilt is the board the games are played on. Where the person lies the cloth is lighter and the cells brighter, with no outline. The lobby now shows the version. (#22, closes #21)

## v7 · 2026-11-25
A plush onesie with ears that show the receiver's state, and a strawberry whose eye closes as they settle. README pictures and `CONTRIBUTING.md`. (#16)

## v6 · 2026-11-25
The suit instead of a body: flat cloth, seams where the gun will not run, a hex grid of haptic cells, a pod at the nape. The per-frame lit relief is removed. (#14)

Also on this day: the repository went public under the Apache License 2.0 (#15).

## v5 · 2026-11-24
The page rebuilt on Depthfield 2.3.0: kit components, the lamp, stretch type, the guardian, settings in a sheet, games placed where they are played. Fixes from review: sound off stops the gun's purr; a sensing phone stops sensing when it changes role. (#12)

## v4 · 2026-11-24
A real reading: a phone on the receiver's back sends its motion to the Go server, which reads breath from it. Https with a self-made certificate. Fixes from review: a sensing session starts from nothing; an old reading is withdrawn. (#11)

## v3 · 2026-11-24
The receiver's state as weather, a breath trace, and a watching third screen.

## v2 · 2026-11-24
The first commit. A redrawn back, the Flip game, and two screens linked by the Go server.

## v1 · 2026-11-24
Four games on one page: Moles, Hedgehogs, Golf, Call. Published only as a claude.ai artifact, before this repository existed, so it has no tag.
